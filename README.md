# Testable Hypothesis Protocol

## O que é

Protocolo operacional para testar hipóteses científicas descartáveis.

## Para quem é

Para quem precisa:
- Testar hipóteses sem blindá-las
- Aceitar refutação sem colapso pessoal
- Documentar processo repetível
- Separar autor de resultado

## O que não é

- Não é filosofia da ciência
- Não é metodologia acadêmica tradicional
- Não é garantia de resultado
- Não é proteção contra erro

## Estrutura

- `PROTOCOL.md` — 9 fases obrigatórias (0→8)
- `CHECKLIST.md` — Verificação sim/não
- `VOCABULARY.md` — Termos precisos
- `DEATH_ACCEPTANCE.md` — Como aceitar refutação
- `TEMPLATE/` — Estrutura reutilizável
- `CASE_STUDIES/` — Exemplos reais

## Princípios

1. **Hipótese ≠ Identidade**  
   O modelo pode morrer. O pesquisador não.

2. **Teste antes de teoria**  
   Sem dado que possa matar, não nasceu.

3. **Documento antes de código**  
   Clareza precede implementação.

4. **Morte honesta**  
   Refutação é resultado, não fracasso.

## Uso

```bash
# 1. Copie o template
cp -r TEMPLATE/ seu-projeto/

# 2. Preencha PROTOCOL.md (fases 0-8)
# 3. Execute CHECKLIST.md antes de cada fase
# 4. Documente resultado em RESULTADO.md
# 5. Se refutado: documente em DEATH_ACCEPTANCE.md
```
